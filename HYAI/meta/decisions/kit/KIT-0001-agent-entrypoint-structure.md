# KIT-0001. Структура общего входа агента

## Решение

Общий вход агента группирует инструкции по этапам работы. Он содержит краткие общие требования и ссылки на источники; `AGENTS.md` остаётся генерируемым файлом из ядра и доменных фрагментов.

## Почему

Сгруппированные инструкции проще применять и поддерживать. Краткая формулировка уменьшает дублирование, не заменяя источники правил.

## Границы

- Решение касается структуры входного текста каркаса, а не конкретных правил доменов.
- Оно не задаёт численную цель экономии и не добавляет runtime, API провайдера или динамическую загрузку контекста.

## Открытые вопросы

- Нет в рамках этого решения.
