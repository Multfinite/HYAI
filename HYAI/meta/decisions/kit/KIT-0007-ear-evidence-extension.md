# KIT-0007. Совместимое дополнение ear/1

## Решение

[А] Владелец поручил перенести опыт исправления ушей в рабочие нормы/шаблоны.
[В] Дополнить существующий домен picture, не создавать отдельный домен ушей,
не менять общий движок HYAI/tools и не помещать проектный канон в каркас.
Смысловые нормы — PIC-0006; здесь только архитектурный контракт расширения.

## Контракт

[В] Сохраняется корень cepi/1. Новые ушные crops получают anatomy_kind=ear,
кадр — дополнение ear_review.schema=ear/1. Явно переданное дополнение проверяется
даже без маркера; старые записи без обоих полей проходят прежние проверки.
Историческая совместимость не означает соответствия новому ушному workflow.

[В] Доменный validator проверяет роли, хэши, координаты, типы, provenance opacity,
ссылки/наблюдения и адресную full_frame приёмку. Он не сегментирует изображение,
не доказывает правду цитаты и не оценивает качество anatomy/light/style.
Тесты отрицательных случаев добавлены до реализации. Общие тесты CEPI не ослаблены.

## Последствия

[В] Новые workflow/templates зарегистрированы, вход агента генерируется из
picture/agents.md. Принятый кадр проекта не является данными HYAI.
Новая версия дополнения потребует явного контракта; скрытых API/моделей нет.
Документ review, одобрение картинки не повышает статус нормы.
