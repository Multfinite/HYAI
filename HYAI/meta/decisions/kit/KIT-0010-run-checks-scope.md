# KIT-0010. Проверки соразмерны правке

## Решение

Полный конвейер `python3 HYAI/tools/run_checks.py` запускается только по необходимости: при
изменении каркаса (`HYAI/core/kernel/**`, `HYAI/tools/**`), манифеста, схем и правил,
определений доменов, профилей или навыков, перед PR/выгрузкой либо по явной просьбе пользователя.
Во всех остальных случаях запускаются только адресные проверки изменённых файлов и затронутой
зоны (`whitespace.py <файлы>`, `check_report.py <отчёты>`, `lint_terms.py --domain <домен>`,
`lint_scopes.py --domain <домен>`, `build_skills.py --check --domain <домен>`, доменные `checks`).
Инструменты без адресного режима запускаются, только если изменённые файлы попадают в их зону.
Норма зафиксирована как `HYAI-INT-31`.

## Почему

Требование всегда гонять полный конвейер (включая 156 проектных тестов) делало обычную правку
одного файла непропорционально дорогой. Большинство проверок имеют адресный режим или доменный
фильтр; полный прогон нужен там, где правка меняет общие правила или готовится к слиянию.

## Границы

- Норма не отменяет ворота `G2`: релевантные проверки обязаны быть зелёными.
- Упавшую проверку нельзя отключить (`HYAI-PERM-N01`); можно только исправить.
- В отчёте перечисляются запущенные проверки и причина, по которой полный конвейер не потребовался.
- Полный конвейер сохраняется как обязательный ворота перед PR и выгрузкой.
