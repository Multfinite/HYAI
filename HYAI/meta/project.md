# Паспорт проекта

Этот файл читает каждый агент в любой задаче. Паспорт описывает **репозиторий**, в который установлен каркас: при подключении к своему проекту замените значения на свои — структура таблиц остаётся.

## Идентичность

| Поле | Значение |
| --- | --- |
| Название | HYAI — Help Your AI |
| Что делает | Каркас правил для ИИ-агента: домены, профили, проверки; переносимое ядро + данные проекта |
| Для кого | Команды и одиночные разработчики, работающие с агентом в одном репозитории |
| Владелец | `maintainer` |
| Статус | release 1.0.0 |

## Активные домены

| Домен | Каталоги продукта | Зачем подключён |
| --- | --- | --- |
| `software` | `src/`, `tests/` | код продукта и его тесты |
| `docs` | `docs/`, `specs/`, `diagrams/` | ТЗ, спецификации, документация, схемы |
| `narrative` | `world/`, `chapters/` | факты мира и текст |
| `picture` | `pictures/` | генерация изображений, конвейеров звеньев и серий через промпт |
| `kit` | `HYAI/core/` | правила, домены, профили |

Домен, которого нет в этой таблице, не должен встречаться в отчётах: `check_report.py` сверяет состав с `active` в манифесте.

## Иерархия источников истины

1. Решение владельца (`HYAI/meta/decisions/project/`, `P-*`).
2. Решение домена (`HYAI/meta/decisions/<domain>/`).
3. Контракт: схема, тип, публичный интерфейс, утверждённая карточка мира.
4. Проверка: тест, линтер, валидатор.
5. Реализация: код, текст.
6. Документация и комментарии.

Нижний уровень не отменяет верхний. Расхождение — дефект нижнего.

## Карта репозитория

| Путь | Что |
| --- | --- |
| `src/`, `tests/` | код (домен `software`) |
| `docs/` | руководства и справка (домен `docs`) |
| `specs/` | ТЗ и технические спецификации (домен `docs`) |
| `diagrams/` | текстовые схемы (домен `docs`) |
| `world/` | факты мира (домен `narrative`) |
| `chapters/` | текст (домен `narrative`) |
| `pictures/` | брифы, промпты, принятые промежуточные звенья и финальные изображения (домен `picture`) |
| `HYAI/core/` | инструкции агенту: правила, домены, профили, процессы |
| `HYAI/meta/` | данные проекта: конфигурация, архитектура, словари, решения, отчёты |
| `HYAI/tools/` | движки проверок этого проекта |

`check_indexes.py` сверяет эту таблицу с фактическими каталогами: расхождение — ошибка.

## Чего в проекте нет

- `<сознательное ограничение>` — чтобы агент не строил планов в направлениях, которые не развиваются.
