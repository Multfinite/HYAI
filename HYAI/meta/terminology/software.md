# Термины домена `software`

| Термин | Значение | Привязка в коде |
| --- | --- | --- |
| `контракт` | Публичный интерфейс, схема или формат, ломать который нельзя без `HYAI-PERM-G02` | `<интерфейс/тип>` |
| `инвариант` | Свойство, которое не может нарушаться ни при каком сценарии | `<проверка>` |
| `модуль` | Единица с одним контрактом и объявленной ценой | `<пакет>` |
| `цена` | Стоимость работы модуля: CPU, память, IO, деньги | `<метрика>` |
| `режим отказа` | Что происходит, когда зависимость недоступна | `<поведение>` |
| `контур` | `public` / `internal` / `restricted` | `<тип Visibility>` |

Правило: если термин используется в коде — он привязан к конкретному типу. Термин без привязки `lint_terms.py` помечает как `warn`: скорее всего, это слово из обсуждения, а не из домена.
