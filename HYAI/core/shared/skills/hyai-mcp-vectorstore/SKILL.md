# simple-files-vectorstore — индекс каталога

## Что даёт

Проходит по каталогу, режет файлы на фрагменты, считает эмбеддинги и ищет по смыслу. Руками
ничего наполнять не нужно.

## Когда брать

- «где в проекте написано про…», а точных слов не помнишь;
- первичный обзор большого незнакомого каталога;
- поиск по документам, а не по символам кода.

Не брать: точный поиск по имени файла, поиск символа, чтение конкретного места — для этого есть
обычное чтение и символьные инструменты.

## Порядок

1. Указать каталог и маски файлов; лишнее исключить до индексации.
2. Проиндексировать.
3. Поиск: вопрос, небольшой `top_k`, затем открыть найденные файлы целиком.
4. После правок — переиндексировать затронутое, иначе поиск будет врать.

## Ловушки

- Индекс устаревает мгновенно после правок; «нашлось» не значит «так и есть сейчас».
- Смена модели эмбеддингов делает старый индекс несопоставимым — нужна переиндексация.
- Крупные каталоги индексируются долго; исключения важнее размера `top_k`.
- Секреты и `.env` исключать до индексации, а не после.

## Без сервера

Текстовый поиск по каталогу и чтение файлов. Медленнее по смыслу, но всегда актуально.

## Проверка

Найденный фрагмент существует в файле в текущем виде.
