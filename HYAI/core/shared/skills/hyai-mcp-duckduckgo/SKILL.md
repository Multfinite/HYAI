# duckduckgo — веб-поиск

## Что даёт

Список результатов по запросу: заголовок, ссылка, краткое описание. Содержимое страниц не
загружает.

## Когда брать

- нужно найти, где вообще написано про тему;
- адрес источника неизвестен;
- нужен обзор нескольких источников, а не один документ.

Не брать: чтение страницы — для этого нужна загрузка; документация библиотеки — для этого есть
специализированный источник.

## Порядок

1. Запрос конкретный: технология, версия, фраза из ошибки.
2. Из выдачи выбрать 2–3 наиболее подходящих источника, отбросив агрегаторы и копии.
3. Загрузить выбранные страницы и читать уже их.
4. При противоречии источников — указать расхождение, а не выбирать удобный.

## Ловушки

- Сниппет — не источник: он может быть устаревшим или вырванным из контекста.
- Выдача персонализируется по региону и языку запроса.
- Частые запросы ограничиваются по темпу: пауза вместо повторов.
- Первые результаты не всегда первоисточник: официальная документация часто ниже.

## Без сервера

Загрузка известных адресов напрямую или работа по ссылкам, которые дал пользователь.

## Проверка

Каждый использованный факт подтверждён загруженной страницей, а не сниппетом.
