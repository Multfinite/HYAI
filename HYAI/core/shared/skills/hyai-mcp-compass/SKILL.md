# compass — обнаружение серверов

## Что даёт

Каталог MCP-серверов: что существует, для чего предназначено. Помогает выбрать сервер, а не
угадывать имя.

## Когда брать

- неизвестно, каким сервером решается задача;
- нужен обзор, прежде чем что-то подключать.

Не брать: работу с уже подключённым сервером; проверку, доступен ли сервер сейчас.

## Порядок

1. Запрос по задаче или категории.
2. Прочитать описание кандидатов, отбросить нерелевантные.
3. Сформулировать пользователю, что именно нужно подключить и зачем.
4. После подключения проверить фактический список инструментов — он и есть источник истины.

## Ловушки

- Найденный сервер не значит подключённый: обнаружение не даёт доступа.
- Каталог отстаёт: описание может не совпадать с текущей версией сервера.
- Подключение сервера — решение пользователя, особенно если он получает доступ к данным.
- Одноимённые серверы от разных авторов различаются поведением.

## Без сервера

Спросить пользователя, какие серверы ему известны, и работать с тем, что уже подключено.

## Проверка

После подключения список инструментов сервера непустой и соответствует задаче.
