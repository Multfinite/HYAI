# Windows-MCP — действия в сеансе Windows

## Что даёт

Видит экран и воздействует на него: снимок, клик, ввод текста, горячие клавиши, запуск
приложений, команды PowerShell.

## Когда брать

- у приложения нет программного интерфейса, только окно;
- нужно проверить, что видит пользователь;
- настройка, доступная только в графическом интерфейсе.

Не брать: работа с файлами и кодом — есть точные инструменты; задачи, решаемые командой.

## Порядок

1. Снимок экрана: что открыто сейчас.
2. Одно действие за шаг: клик или ввод.
3. Новый снимок как проверка результата.
4. Если действие не дало эффекта — не повторять вслепую, а найти окно или элемент заново.

## Ловушки

- Действия видны пользователю и необратимы: закрытие окна может потерять данные.
- Координаты зависят от разрешения и масштаба: после изменения размера окна — новый снимок.
- Пароли и токены не вводятся в поля без прямого указания.
- Элементы интерфейса меняются между версиями приложения: ищи по подписи, а не по позиции.

## Без сервера

Команды оболочки и файловые операции: часто задачу можно решить без управления экраном.

## Проверка

Снимок после действия показывает ожидаемое состояние.
