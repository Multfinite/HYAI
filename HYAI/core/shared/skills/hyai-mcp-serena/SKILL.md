# serena — символы вместо текста

## Что даёт

Понимает код через языковой сервер: символы, ссылки, диагностика, правки по символам, а не по
строкам. Читает меньше, ошибается реже.

## Когда брать

- нужно найти, где объявлено и кто использует;
- правка метода или функции, а не файла целиком;
- переименование с обновлением ссылок;
- проверка ошибок после правки без полной сборки.

Не брать: правка конфигурации, разметки без символов, работа с не-кодом.

## Порядок

1. Активировать проект абсолютным путём; повторный вызов просто переключает проект.
2. Обзор символов файла — карта без тел.
3. Поиск нужного символа с телом; при необходимости — глубина, чтобы получить членов класса.
4. Кто использует символ — ссылки с фрагментами вокруг.
5. Правка: тело символа целиком, вставка до или после символа, точечная замена внутри.
6. Диагностика файла, затем переименование, если нужно, — средством сервера, не вручную.

## Ловушки

- Путь указывается от корня проекта, а не абсолютный.
- Нумерация строк начинается с нуля.
- Замена тела символа затирает его целиком: прочитай тело заранее.
- Сеансовая память сервера локальна для проекта и не заменяет общую память.
- Команды оболочки через сервер выполняются на машине как обычные: считай это продакшеном.

## Без сервера

Чтение файлов и поиск по тексту; правки — построчно. Медленнее и рискованнее при переименованиях:
ссылки придётся искать вручную.

## Проверка

После правки — диагностика файла и повторное чтение изменённого символа.
