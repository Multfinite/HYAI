# Код: несколько инструментов на один репозиторий

## Участники и что у каждого

| Сервер | Роль | Правки | Что устаревает |
| --- | --- | --- | --- |
| serena | символы, ссылки, диагностика | да, по символам | состояние языкового сервера |
| codegraph | архитектурный граф | нет | индекс после правок |
| codebase-memory | карта модулей | нет | карта после изменений |
| everything-search | поиск файлов и текста | нет | индекс ОС |
| filesystem | чтение и запись файлов | да, построчно | — |
| git | история и коммиты | коммиты | — |

## Что меняется от комбинации

- Один инструмент правки — нет конфликта записи. Два — появляется риск перетереть правку.
- Добавили граф — видно последствия, но граф отстаёт от рабочего дерева.
- Добавили карту — быстрый старт, но карта описывает прошлое состояние.
- Добавили поиск по индексу ОС — он видит и то, что вне репозитория, и не видит свежие файлы.

## Один писатель на файл

Правку файла выполняет **один** инструмент за шаг. Остальные — только читают. Если нужно
переключиться (например, правка символа недоступна), сначала перечитать файл: предыдущая правка
могла изменить строки.

## Авторитет

| Вопрос | Кто отвечает |
| --- | --- |
| где объявлен символ, кто его использует | символьный сервер |
| как модули связаны | граф |
| что написано в файле прямо сейчас | чтение файла |
| почему так исторически | история git |
| что изменено и готово к коммиту | состояние git |

Ответ графа или карты — гипотеза, которую подтверждает чтение кода.

## Порядок

1. Карта: граф или память о кодовой базе — где вообще искать.
2. Символы: обзор файла, поиск объявления, ссылки.
3. Правка одним инструментом, минимальным диффом.
4. Диагностика после правки.
5. Переименование — средством сервера, не вручную.
6. Коммит — только после проверки диффа.

## Ошибки комбинации

- Правка через два инструмента без перечитывания — потеря изменений.
- Доверие графу после правок — вывод о связях по устаревшему снимку.
- Переименование вручную при доступном символьном — битые ссылки.
- Коммит без чтения диффа — в коммит попадает посторонняя правка.

## Без символьных инструментов

Чтение файлов и поиск по тексту; правки построчно; переименование — с ручной проверкой ссылок.
Скажи прямо, что символьные операции недоступны: это влияет на оценку риска.
