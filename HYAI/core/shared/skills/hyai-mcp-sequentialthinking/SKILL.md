# sequentialthinking — явная цепочка шагов

## Что даёт

Один инструмент, который принимает одну мысль за вызов. Памяти нет: после завершения цепочки
остаётся только текст в контексте.

## Когда брать

- задача распадается на четыре и больше шагов;
- есть два-три варианта, и нужен явный выбор с ценой каждого;
- отладка: несколько гипотез проверяются по очереди.

Не брать: правка в один шаг, поиск факта, вопрос про API библиотеки. Цепочка не заменяет
проверку — тест, лог и чтение файла остаются обязательными.

## Порядок

1. Первый вызов — постановка задачи и оценка числа мыслей (`totalThoughts`).
2. Одна мысль — один шаг: наблюдение, вывод или действие.
3. Ошибка — `isRevision: true` и `revisesThought: <номер>`, а не новая цепочка с нуля.
4. Альтернатива — `branchFromThought: <номер>` и `branchId`; сравни ветки и оставь одну.
5. Оценка занижена — `needsMoreThoughts: true` и увеличить `totalThoughts`.
6. Завершение — `nextThoughtNeeded: false`, сразу итог: что решили, почему, следующий шаг.

## Ловушки

- Весь план в первый `thought` — ветвление и ревизии перестают работать.
- Секреты в тексте мысли: она уходит в контекст модели.
- Двадцать мыслей «на всякий случай» — токены и задержка без результата.
- Итог цепочки не сохраняется: нужное переноси в память или в отчёт явно.

## Без сервера

План в ответе: шаги, проверка каждого, итог. Теряется только машинный номер мыслей.

## Проверка

Цепочка закончена `nextThoughtNeeded: false` и итогом, а не обрывом на середине.
