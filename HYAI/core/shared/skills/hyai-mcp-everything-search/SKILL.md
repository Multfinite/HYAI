# everything-search — поиск по индексу машины

## Что даёт

Отвечает почти мгновенно, потому что опирается на индекс операционной системы, а не на обход
диска. Возвращает пути, а не содержимое.

## Когда брать

- имя файла известно частично;
- нужно понять, где на машине лежит документ или проект;
- поиск по содержимому текстовых файлов во многих каталогах сразу.

Не брать: поиск символа в коде; чтение найденного; работа на не-Windows машине.

## Порядок

1. Запрос по маске имени или по фрагменту текста.
2. Из списка путей выбрать нужные; лишние отбросить по расширению и каталогу.
3. Открыть найденное обычным чтением файла.
4. Если файл свежий и не находится — проверить обычным обходом каталога.

## Ловушки

- Индекс обновляется с задержкой: только что созданный файл может отсутствовать.
- Часть форматов не индексируется по содержимому — только по имени.
- Результат — пути; содержимое надо читать отдельно.
- Доступность зависит от платформы и прав службы индексации.

## Без сервера

Обход каталогов и текстовый поиск. Медленнее, но не зависит от индекса.

## Проверка

Каждый путь из выдачи существует и открывается.
