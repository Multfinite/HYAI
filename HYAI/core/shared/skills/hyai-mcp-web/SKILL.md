# Веб: несколько источников

## Участники и что у каждого

| Сервер | Что даёт | Когда лучший | Ограничение |
| --- | --- | --- | --- |
| context7 | документация библиотеки по версии | вопрос про API | только публичные пакеты |
| duckduckgo | список источников | адрес неизвестен | сниппет не источник |
| fetch | страница как текст | точный адрес, статика | без JavaScript |
| playwright | страница после исполнения | интерфейс, SPA | медленнее, состояние сессии |

## Что меняется от комбинации

- Только поиск — много ссылок, мало фактов.
- Добавили загрузку — появился текст, но версия страницы неизвестна.
- Добавили документацию по версии — появился авторитет по API, но только для публичных пакетов.
- Добавили браузер — появились страницы без статического текста, но и риск принять чужое
  состояние интерфейса за факт.

## Порядок выбора

1. Вопрос про библиотеку → документация по версии.
2. Адрес неизвестен → поиск, затем загрузка выбранных страниц.
3. Страница пустая или собирается скриптами → браузер.
4. Интерфейс нужно проверить после изменения → браузер, снимок как доказательство.

## Версии и даты

У каждого внешнего факта фиксируются: адрес, версия (если известна), дата обращения. Расхождение
версий — не ошибка источника, а разные состояния; указывай оба.

## Ошибки комбинации

- Ответ по сниппету без открытия страницы.
- Документация последней версии применена к установленной старой.
- Статическая загрузка «доказала» отсутствие элемента, который создаётся скриптом.
- Смешаны результаты поиска разных языков и регионов без указания этого.

## Маркировка

Внешний факт помечается как внешний и не выдаётся за проверенное поведение проекта. Локальная
проверка (запуск, чтение кода) всегда сильнее внешней страницы.

## Без сети

Скажи, что вопрос не проверен в сети, и опирайся только на локальные данные и знания
пользователя.
