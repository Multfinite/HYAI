# `analysis` — общая часть

Машинное описание — [`profile.yaml`](profile.yaml). Домен подключает его полем `includes` и добавляет своё.

## Что сюда входит

- Механика: один вопрос, факты отдельно от гипотез, варианты с ценой, рекомендация, открытые вопросы.
- Артефакты: отчёт `report_kind: analysis` и `Q-*`.
- Процесс: `audit` (исследование без правок).

## Что остаётся в домене

- `topic` и `thought_process` — предмет разбора.
- Свой чек-лист: что именно проверять в коде, в документе, в корпусе мира.
- Результат разбора зависит от домена: вариант решения, вариант формулировки, вариант разрешения противоречия.

## Чего разбор не делает нигде

Не правит файлы, кроме собственного отчёта: результат — материал для решения, а не решение (`HYAI-INT-09`).
