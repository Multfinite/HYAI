# Правила слияния

Четыре уровня: ядро → домен → профиль → задача. Каждый следующий может **добавить** и **уточнить**, но не отменить предыдущий.

## 1. Матрица

| Элемент | Ядро | Домен | Профиль |
| --- | --- | --- | --- |
| `PERM-N` | задаёт | не меняет | не меняет |
| `permissions` | задаёт | не меняет | **не содержит** |
| `authority.users` | — | задаёт | не меняет |
| `visibility` | инвариант «закрыто по умолчанию» | задаёт значения | не меняет |
| маркеры `[А]/[И]/[В]/[Г]/[?]` | задаёт алфавит | может уточнить источник `[А]` | не меняет |
| `workflows` | универсальные | доменные | один основной на профиль |
| `templates` | формы результата | предметные формы | формы профиля |
| `lint` | проектные правила | доменные правила | — |
| `checks` | обязательные | добавляет | добавляет |

## 2. Запреты

`MERGE-01`. `non_overridable` не переопределяется ничем. `check_manifest.py` возвращает `rc=1`.
`MERGE-02`. `permissions.read.exclude` можно только расширять: домен и профиль добавляют пути, не удаляют.
`MERGE-03`. `permissions.execute.allow` не расширяется без явного `overrides:` в манифесте и одобрения владельца.
`MERGE-04`. Любое переопределение ключа профилем обязано быть объявлено в `overrides:` своего `profile.yaml`; иначе `rc=1`.
`MERGE-05`. Домен не может объявить `visibility` шире ядерного инварианта: значение по умолчанию всегда «закрыто».
`MERGE-06`. Профиль не может повысить нормативность документа: `implementation` → `contract` только через решение домена и `HYAI-PERM-G01`.

## 3. Композиция нескольких доменов

Если активно больше одного домена (`active` — список), действуют правила:

| Вопрос | Правило |
| --- | --- |
| Чей документ | Домен определяется по `path_map`; у файла ровно один домен |
| Чей контур доступа | Контур документа — контур его домена; сводка по двум доменам наследует **строжайший** |
| Чья терминология | Композит: `HYAI/meta/terminology.md` + `HYAI/meta/terminology/<domain>.md`; два разных определения одного термина — ошибка |
| Чей `architecture` | `HYAI/meta/architecture.md` — хаб без норм, ссылается на `HYAI/meta/architecture/<domain>.md` |
| Чья проверка | Объединение `checks` всех активных доменов плюс ядро |

## 4. Проверяемость

`MERGE-07`. Каждое правило этого файла проверяется `check_manifest.py` или `check_domains.py`; пометка `enforced: prose-only` допустима только с причиной.
