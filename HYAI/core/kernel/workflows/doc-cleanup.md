# `doc-cleanup` — текст без потери смысла

Цель — убрать пустое, сохранив каждую норму, число, пример и цитату требования дословно.

Правила: домен `docs` — `HYAI/core/domains/docs/text.md` (`DOC-TXT-01..14`); для художественного текста действует `HYAI/core/domains/narrative/text.md` (`NR-TXT-01..14`) с другим набором требований — там защищается голос, а не формулировка нормы.

## Порядок

1. **Инвентаризация.** Какие документы чистим и зачем; что в них нормативного (правила с ID, числа, контракты, примеры).
2. **Снимок.** Для блоков, которые нельзя менять по смыслу (примеры кода, CLI, сообщения об ошибках, цитаты), зафиксировать `sha256` до правки.
3. **Правка.** Удаляется: пересказ предыдущего абзаца, «важно отметить», «следует понимать», рассуждения о очевидных следствиях, дубли норм из соседних файлов (заменяются ссылкой).
4. **Проверка.** `sha256` защищённых блоков совпадает; все ID правил на месте; ссылки целы; `run_checks.py` зелёный.
5. **Отчёт** `task`: сколько строк удалено, какие ID правил сохранены (перечислить), что защищено хешем.

## Запреты

- Менять формулировку нормы «заодно».
- Удалять пример, не убедившись, что он не единственное объяснение правила.
- Сокращать документ, который не читали целиком.
