# `narrative/export-book`

Сборка читательской, игровой или мастерской версии корпуса. Правила — [`../policy.md`](../policy.md) §9 (`NR-EXP-01..05`), схема пресетов — [`../schema/access.yaml`](../schema/access.yaml), движок — [`HYAI/tools/build_export.py`](../../../../tools/build_export.py).

## 1. Выбрать пресет

Пресет — пара «роль × призма»: `public`, `reader`, `master`. Пресета нет в схеме — сборка не начинается (код `2`), а не собирается «примерно как reader».

## 2. Проверить статусы

`status_floor` пресета: `draft` не выгружается никому, даже при `visibility: public`. Отчёт о сборке начинается с числа отброшенных по статусу документов: «сборка пуста» — это результат, а не ошибка.

## 3. Собрать

```bash
python3 HYAI/tools/build_export.py --domain narrative --preset reader --dry-run   # что войдёт
python3 HYAI/tools/build_export.py --domain narrative --preset reader             # сборка
```

Конвейер: пресет → отбор по доступу (`resolve_access.py`) → пред-фильтрация чтения (`NR-READ-01`) → сборка из источников → очистка служебного (`NR-EXP-03`) → каталог `exports.dir` пресета.

## 4. Проверить

1. В каталоге выгрузки нет frontmatter, маркеров `[А]/[И]/[В]/[Г]/[?]`, внутренних ID, ссылок на решения и путей репозитория (`NR-EXP-03`).
2. `lint_scopes.py --domain narrative` не находит закрытого в открытой выгрузке.
3. Список документов совпадает с ожидаемым; расхождение объяснено.

## 5. Свести

Отчёт `task`: пресет, число документов, число отброшенных по статусу и по контуру, результат проверок, что осталось за контуром и почему. Без отчёта выгрузка считается незаявленной (`NR-EXP-04`, `HYAI-ART-22`).

## Чего не делать

| Нельзя | Почему |
| --- | --- |
| собирать из «всего, что выглядит публичным» | метки доступа важнее впечатления (`NR-READ-01`) |
| вырезать абзацы из уже прочитанного текста | закрытое уже попало в контекст — вырезание не отменяет прочтения (`NR-READ-02`) |
| ставить `status: approved` ради выгрузки | статус — решение владельца (`HYAI-PERM-N05`) |
| скрывать, что сборка пуста | пустая сборка — результат, а не ошибка (`NR-EXP-02`) |
| выгружать без отчёта | выгрузка без отчёта считается незаявленной (`HYAI-ART-22`) |

## Критерий готовности

- [ ] Пресет объявлен в схеме; иного не выдумано.
- [ ] Порог статуса соблюдён; отброшенное посчитано.
- [ ] Служебное вычищено; проверка каталога пройдена.
- [ ] Отчёт записан и внесён в индекс.
