# `narrative/analysis`

Машинное описание профиля — [`profile.yaml`](profile.yaml): зона, процесс, критерии готовности.

**Тема:** противоречия, пробелы и провисания в корпусе.
**Мыслительный процесс:** длинная цепочка перекрёстных проверок — каждое противоречие подтверждается двумя местами, каждый пробел превращается в вопрос.

## Активация

Агент предлагает этот профиль для аудита корпуса, или пользователь называет его сам (`HYAI-INT-08`).

## Что производит

Отчёт `report_kind: analysis` в `HYAI/meta/reports/narrative/`: вопрос → разбор с цитатами и маркерами → варианты разрешения с ценой → рекомендация → открытые вопросы.

## Чего не делает

- Не правит корпус (`HYAI-INT-09`): найденное противоречие — материал для решения владельца.
- Не придумывает недостающие факты, чтобы «всё сходилось».
- Не выдаёт стилистическое предпочтение за противоречие.
