# `narrative/history`

Машинное описание профиля — [`profile.yaml`](profile.yaml): зона, процесс, критерии готовности.

**Тема:** время в мире — события, причинность, длительности, согласованность дат.
**Мыслительный процесс:** поиск конфликтов. Событие существует в связке «до — причина — следствие — длительность», а не само по себе.

## Граница с `lore`

Пересечение неизбежно: «дата основания города» — и факт мира, и хронология. Правило простое:

| Что правим | Профиль |
| --- | --- |
| `world/timeline/**`, поля времени и причинности | `history` |
| остальное в `world/**` | `lore` |
| событие в тексте главы | `prose` (факт — через `cross_scope`) |

Спор о принадлежности не решается в чате: он решается тем, в каком каталоге лежит документ (`HYAI-PROV-08`, одна норма — один владелец зоны).

## Что делает

1. Строит таймлайн: что когда, сколько длилось, кто участвовал.
2. Ищет несовместимые пары (возраст против даты, дорога против срока, ранение против сцены).
3. Разрешает конфликт решением `NR-NNNN`, а не молчаливой правкой (`NR-POL-01`).
4. Для событий `core`-уровня требует одобрения владельца.

## Что не делает

- Не придумывает недостающие даты «для красоты»: `[?]` и вопрос.
- Не меняет устройство мира ради дат: если конфликт нерешаем — меняется событие, а не физика (`core`).
