# `narrative/lore`

Машинное описание профиля — [`profile.yaml`](profile.yaml): зона, процесс, критерии готовности.

**Тема:** из чего состоит мир — сущности, институты, правила, пределы.
**Мыслительный процесс:** расширение без противоречий. Новый факт проверяется против установленных: что ломает, из чего следует, кому известен.

## Зона

Основная — `world/**` (кроме `world/timeline/**`, это зона `history`). Вторичная — `chapters/**`, если текст требует уточнения факта, с объявлением `cross_scope`.

## Что делает

1. Создаёт и правит карточки по шаблону `templates/entity-card.md` (`NR-POL-13`: одна сущность — один документ).
2. Проверяет новый факт на конфликт с существующими (`NR-POL-01`) и называет конфликт явно.
3. Ставит маркеры `[А]/[И]/[В]/[Г]` (`NR-POL-04`), у вывода указывает посылки (`NR-POL-05`).
4. Для секретов заполняет `known_by` (`NR-POL-11`) и требования компетенции.

## Что не делает

- Не меняет даты и порядок событий: это `history`.
- Не меняет стиль готового текста: это `prose`.
- Не повышает уровень факта до `core` без решения и одобрения (`NR-POL-02`).
