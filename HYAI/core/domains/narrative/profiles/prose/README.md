# `narrative/prose`

Машинное описание профиля — [`profile.yaml`](profile.yaml): зона, процесс, критерии готовности.

**Тема:** сцены, диалоги, ритм, голос, композиция.
**Мыслительный процесс:** слышать голос. Сначала ритм и точка зрения, потом слова. Художественный текст не обязан быть коротким — он обязан быть живым.

## Зона

Основная — `chapters/**`, `drafts/**`. Вторичная — `world/**`: если текст требует уточнения факта, профиль вносит его и объявляет в `cross_scope` (`HYAI-ART-14`, `NR-POL-03`).

## Что делает

1. Пишет и правит текст, сохраняя голос (`NR-POL-08`).
2. Чистит воду по процессу `narrative/prose-cleanup`, защищая цитаты хешем.
3. Фиксирует факты, которые тронул, в отчёте.

## Что не делает

- Не меняет факты под видом стиля (`NR-POL-07`): это две задачи.
- Не цитирует черновик как источник (`NR-POL-09`).
- Не выравнивает речь персонажа под литературную норму.
