# Схемы домена narrative

Строгая зона домена: профили не могут переопределять эти файлы.

| Файл | Что задаёт |
| --- | --- |
| [`authority.yaml`](authority.yaml) | Уровни нормативности, статусы, допустимые переходы, маркеры |
| [`access.yaml`](access.yaml) | Контуры доступа, правила, шкала, пресеты выгрузки и порог статуса |
| [`competence.yaml`](competence.yaml) | Каталог доменов знания и формулировки «знает до …» |

Оверлей frontmatter домена — в общей зоне: `HYAI/meta/schema/domains/narrative.yaml`.
