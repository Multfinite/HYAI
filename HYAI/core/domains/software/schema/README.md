# Схемы домена software

Строгая зона домена: профили не могут переопределять эти файлы.

| Файл | Что задаёт |
| --- | --- |
| [`authority.yaml`](authority.yaml) | Уровни нормативности, статусы, допустимые переходы, маркеры |
| [`access.yaml`](access.yaml) | Контуры доступа, правила, пресеты выгрузки |

Оверлей frontmatter домена — в общей зоне: `HYAI/meta/schema/domains/software.yaml`.
