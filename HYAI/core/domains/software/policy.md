# `SW` — правила домена software

Правила ядра (`PERM`, `PROV`, `ART`, `DEC`, `INT`) действуют здесь целиком. Ниже — только то, что специфично для кода.

## 1. Источник истины

`SW-POL-01`. Порядок доверия: принятое решение (`HYAI/meta/decisions/software/`) → контракт (схема, тип, публичный интерфейс) → тест → реализация → комментарий → документация. Комментарий не является источником истины никогда.
`SW-POL-02`. Расхождение кода и контракта — дефект кода, а не повод поправить контракт «по факту». Правка контракта — отдельное решение (`HYAI-PERM-G02`).

## 2. Изменение

`SW-POL-03`. Сначала проверка, потом код: тест, воспроизведение, бенчмарк. Код без проверяемого результата не принимается.
`SW-POL-04`. Существующий тест не ослабляется (`HYAI-PERM-N01`): удаление, `skip`, сужение ассерта требуют решения и одобрения.
`SW-POL-05`. Баг сначала воспроизводится падающим тестом, потом исправляется. Исключение — дефект, воспроизведение которого невозможно; тогда в отчёте указывается, что именно не удалось воспроизвести.
`SW-POL-06`. Рефакторинг не меняет поведение. Если поведение меняется — это не рефакторинг, а изменение, и оно идёт своим процессом.

## 3. Зависимости и границы

`SW-POL-07`. Новая зависимость — только с обоснованием: что даёт, чем заменить, что будет при её удалении (`HYAI-PERM-G03`).
`SW-POL-08`. Слои не нарушаются: домен не импортирует инфраструктуру, инфраструктура не содержит бизнес-правил. Нарушение фиксируется в `HYAI/meta/architecture/software.md` как анти-паттерн, а не обсуждается в чате.
`SW-POL-09`. Глобальное состояние и скрытые синглтоны — запрещены, кроме явно объявленных в архитектуре.

## 4. Ошибки

`SW-POL-10`. Ошибка не проглатывается: либо обрабатывается осознанно, либо пробрасывается с контекстом. Пустой `except`/`catch` — дефект `P1`.
`SW-POL-11`. Сообщение об ошибке содержит, что произошло, где и что делать. Стек-трейс — не сообщение пользователю.

## 5. Документация кода

`SW-POL-12`. Документация описывает контракт, а не реализацию. Документ, который придётся править при каждом рефакторинге, написан неверно.
`SW-POL-13`. Ссылка из документации на код — с путём и, где полезно, строкой (`../src/auth.py#L42`); такая ссылка проверяется `check_links.py`.
