# Доступ в домене `software`

Механика ядра (`HYAI-PERM-N02`, `HYAI-PERM-N06`, наследование контура) — в [`../../kernel/policies/`](../../kernel/policies/README.md). Здесь — значения для кода: три контура, без ролей и призм.

| `visibility` | Что входит | Куда можно |
| --- | --- | --- |
| `public` | README, публичный API, пользовательские гайды, лицензии | Всё, включая внешние выгрузки |
| `internal` | `HYAI/meta/*`, спеки, ADR, отчёты, runbooks, внутренние модули | Только внутри репозитория и команды |
| `restricted` | Модели угроз, закрытые алгоритмы, ключи доступа к продовым данным, инциденты | Только при явном `contour: restricted` в задаче |

## Правила

1. Контур `restricted` не цитируется в `public` и `internal` сводках — ни фрагментом, ни пересказом.
2. Код и его секреты: `.env*`, `*.pem`, `*.key` закрыты на чтение во всех контурах (`permissions.read.exclude`).
3. Утечка через артефакт: сгенерированный пример, лог или фикстура наследует самый строгий контур своих источников.
4. Литературных контуров (`spoiler`, `author`, `system`) в домене нет: значение из другого домена здесь — ошибка.
