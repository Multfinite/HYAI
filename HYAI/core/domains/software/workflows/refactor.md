# `software/refactor`

Также используется профилем `architect` для проектирования: результат — решение и спека, а не только переписанный код.

1. **Фиксация поведения.** Тесты зелёные до начала. Нет тестов — сначала тесты, потом рефакторинг.
2. **Границы.** Что остаётся неизменным: публичный интерфейс, формат данных, наблюдаемое поведение.
3. **Шаги.** Серия малых обратимых изменений, каждое — с зелёным прогоном.
4. **Проверка.** Поведение не изменилось: тот же набор тестов, тот же результат.
5. **Решение** (для `architect`): `HYAI/meta/decisions/software/SW-NNNN-*.md` с ценой и последствиями.

Признак ошибки: дифф вырос настолько, что его нельзя проверить за один проход — разбить на части.
