# Нормативность в домене `software`

Общая механика — в [`../../kernel/policies/provenance.md`](../../kernel/policies/provenance.md). Здесь — словарь значений для кода.

## Уровни

| `authority` | Что это | Цена изменения | Одобрение |
| --- | --- | --- | --- |
| `invariant` | Системное свойство: безопасность, целостность данных, совместимость | Ломает всё, что выше по стеку | `HYAI-PERM-G01` |
| `contract` | Публичный интерфейс, схема данных, формат файла, протокол | Ломает внешних потребителей | `HYAI-PERM-G02` |
| `implementation` | Внутреннее устройство: классы, приватные функции, алгоритмы | Локальная | нет |
| `convention` | Стиль, именование, структура каталогов | Косметическая | нет |
| `experimental` | Ветка, прототип, фича-флаг | Нулевая: удаляется целиком | нет |
| `none` | Отчёт, заметка, черновик | — | — |

## Статусы

`draft` → `review` → `approved` → (`superseded` | `deprecated`). Статус ставит человек: агент предлагает `review`, но не `approved` (`HYAI-PERM-N05`).

`deprecated` означает «действует, но не использовать в новом коде» — это не то же, что `superseded` («заменено другим документом»).

## Чего здесь нет

Литературного деления `core / setting / detail / presentation` в домене `software` нет: попытка поставить такое значение — ошибка `frontmatter.py`, а не «похожее по смыслу».
