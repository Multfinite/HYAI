# `software/analysis`

Машинное описание профиля — [`profile.yaml`](profile.yaml): зона, процесс, критерии готовности.

**Тема:** разбор неясной задачи до принятия решения.
**Мыслительный процесс:** увеличенная цепочка рассуждений и проверок — факты отделяются от гипотез, гипотезы получают условия проверки, варианты — цену.

## Активация

Агент предлагает этот профиль, когда задача неясна, или пользователь называет его сам (`HYAI-INT-08`). Молча не включается: длинная цепочка рассуждений стоит времени.

Если пользователь просит «просто сделай», а задача явно неясна, агент может **предложить** этот профиль одной строкой и продолжить в обычном режиме, если предложение отклонено.

## Что производит

Отчёт `report_kind: analysis` в `HYAI/meta/reports/software/`: вопрос → разбор → варианты с ценой → рекомендация → открытые вопросы.

## Чего не делает

- Не правит код и документы: результат разбора — материал для решения, а не решение (`HYAI-INT-09`).
- Не выдаёт гипотезу за факт: `[Г]` всегда с условием проверки (`HYAI-PROV-01`).
- Не рекомендует вариант, цену которого не оценил.
- Не разбирает несколько вопросов в одном отчёте: два вопроса — два разбора.
