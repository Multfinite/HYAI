# Модульная карточка

Обязательна для модуля, у которого есть цена (CPU, память, IO, деньги) или внешние отказы. Форма перенесена из исходной системы («карточка цены магии») и обобщена.

**Если данных нет:** цена не оценивается на глаз — `[Г]` и план измерения.
