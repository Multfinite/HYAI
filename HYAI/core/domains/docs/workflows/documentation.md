# `docs/documentation`

1. **Читатель и вопрос.** Кто читает и что он хочет узнать первым. Один документ — один читатель (`DOC-POL-04`).
2. **Источник.** Что описываем: код, поведение, процедура. Ссылки на код — с путём и строкой (`DOC-POL-08`).
3. **Структура.** Вопрос → короткий ответ → пример → подробности → крайние случаи. Ответ не прячется в конце.
4. **Примеры.** Запускаемые и правдоподобные. Секреты не копируются из окружения (`HYAI-PERM-N02`).
5. **Проверка.** Примеры выполняются; ссылки проходят `check_links.py`; вода вычищена (`DOC-POL-06`).
6. **Комментарии в коде** — только «почему» и только там, где код не объясняет сам (`DOC-POL-13`).
