# Домен `docs`

Отвечает за всё, что **объясняет и предписывает словами и схемами**: техническое задание, техническую спецификацию, документацию, руководства, комментарии в коде, диаграммы.

## Чем отличается от `software`

| Вопрос | `software` | `docs` |
| --- | --- | --- |
| Что производит | код, тесты, контракты модулей | ТЗ, спецификации, руководства, схемы |
| Источник истины | контракт и тест | требование и согласованная схема |
| Проверка результата | прогон тестов | читаемость, полнота, согласованность с кодом |
| Типичная ошибка | код расходится с контрактом | документ описывает то, чего нет |

Граница проста: **контракт модуля** (что принимает и отдаёт функция) — `software`; **требование к системе** (зачем и при каких условиях) — `docs`.
