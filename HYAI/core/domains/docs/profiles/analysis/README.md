# `docs/analysis`

Машинное описание профиля — [`profile.yaml`](profile.yaml). Общая механика разбора — в [`../../../shared/profiles/analysis/README.md`](../../../../shared/profiles/analysis/README.md).

**Тема:** где документация неполна, противоречива или расходится с кодом.
**Мыслительный процесс:** перекрёстная проверка — требование против кода, документ против документа.

## Что производит

Отчёт `report_kind: analysis` в `HYAI/meta/reports/docs/`: вопрос → разбор со ссылками → варианты исправления с ценой → рекомендация → открытые вопросы.

## Чего не делает

- Не правит документы (`HYAI-INT-09`): найденное — материал для решения владельца.
- Не выдаёт «мне так понятнее» за противоречие.
- Не додумывает недостающее требование.
