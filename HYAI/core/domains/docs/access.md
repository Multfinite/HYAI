# Доступ в домене `docs`

Плоская модель: ролей и призм нет. Документ либо публикуется, либо закрыт.

| `visibility` | Что входит | Куда можно |
| --- | --- | --- |
| `public` | Пользовательские руководства, публичные спецификации, README | Внешние выгрузки, сайт документации |
| `internal` | Внутренние ТЗ, архитектурные описания, runbook | Репозиторий и команда |
| `restricted` | Документы по безопасности, инцидентам, закрытым алгоритмам | Только с явным `contour: restricted` |

## Правила

1. Контур наследуется: ТЗ, описывающее закрытую подсистему, закрыто само.
2. Выгрузка в публичный пресет идёт через `build_export.py --domain docs --preset public`; документ с `restricted` в неё не попадает (`DOC` + `HYAI-PERM-N04`).
3. Секреты и ключи не попадают в примеры: пример выдуманный, но правдоподобный, а не скопированный из `.env` (`HYAI-PERM-N02`).
