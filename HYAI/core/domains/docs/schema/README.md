# Схемы домена `docs`

Строгая зона домена: профили не могут переопределять эти файлы.

| Файл | Что задаёт |
| --- | --- |
| [`authority.yaml`](authority.yaml) | Уровни `normative/descriptive/illustrative/informative`, статусы, маркеры |
| [`access.yaml`](access.yaml) | Контуры доступа, проверки, пресет публичной выгрузки |

Оверлей frontmatter домена — в общей зоне: `HYAI/meta/schema/domains/docs.yaml`.
