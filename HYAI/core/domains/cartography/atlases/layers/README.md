# Layers

Один тематический dataset на стабильный `layer_id`; common vector-layer contract — [`geospatial-layer.yaml`](../../templates/geospatial-layer.yaml), климатический — [`climate-layer.yaml`](../../templates/climate-layer.yaml). Сохраняй provenance и temporal validity при каждой производной операции.

Рекомендуемые группы: `tectonics/`, `currents/`, `climate/`, `atmosphere/`, `political/`, `settlements/`, `routes/`. Raster scientific inputs не становятся картографической выдачей и требуют явного источника/одобрения.
