# Systems

Храни записи звёздных систем по [`system-record.yaml`](../../templates/system-record.yaml). IDs звёзд/систем стабильны; расстояние и stellar parameters всегда сопровождаются единицами, источником и uncertainty. Один файл — одна система/версия, если проектная схема не задаёт иное.
