# Bodies

Храни записи планет и иных тел по [`body-record.yaml`](../../templates/body-record.yaml). Для каждого тела задаются parent system/star, фигура и размеры, frame/datum/CRS, pole orientation, rotation period/day length и orbital period/year. Неизвестные параметры остаются явно неизвестными.
