# Exports

Сохраняемые deliverables — SVG или другой явно указанный векторный формат с metadata sidecar и hash. Проверяй export по [`vector-export-checklist.md`](../../templates/vector-export-checklist.md). Не сохраняй сюда screen captures, PNG/JPEG/TIFF или raster basemap.
