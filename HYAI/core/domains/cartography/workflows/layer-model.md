# Создание тематического векторного слоя

1. Определи доменный тип слоя: тектоника, течение, климат/атмосфера, географические названия, политическая граница, город или маршрут.
2. Для каждого слоя заполни stable `layer_id`, `body_id`, `crs_id`, geometry type, units, time/epoch, source, method, authority, status и uncertainty.
3. Для плит сохрани границы и движение в заданной reference frame с единицами/эпохой; для океанических течений — направление, временную применимость и `warm`/`cold`/`neutral` относительно указанного baseline.
4. Для атмосферы укажи высотный уровень, temperature/precipitation units и time resolution. Производные поля содержат версию модели, inputs и ограничения.
5. Каждая climate classification layer использует Köppen–Geiger и документирует период, temperature/precipitation inputs, threshold/version и не-земную адаптацию при необходимости.
6. Политические/географические объекты содержат stable ID, имена/язык/алиасы, временную действительность, источник и статус спорности.
7. Проверь топологию и ссылки на тело/CRS на целевом инструменте; экспортируй данные без неоговорённого изменения координат.

**Готово, когда:** источник, метод, временные пределы, CRS/units, геометрия и семантика слоя проверяемы; производные значения отличены от канона.
