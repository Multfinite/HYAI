# Intake планетарного атласа

1. Уточни цель и аудиторию атласа, целевое тело/систему и типы будущих слоёв; не выводи геометрию и числа из прозы.
2. Зафиксируй stable IDs и владельца данных; для narrative-канона следуй [`P-0005`](../../../../meta/decisions/project/P-0005-cartography-world-canon.md).
3. Для каждого слоя спроси источник, эпоху/время, единицы, координатную систему, ожидаемую точность и ограничения доступа.
4. Уточни формат сохраняемой выдачи: SVG или иной явный векторный формат. Отдельно зафиксируй нужен ли экранный интерактивный 3D-viewer; его пиксельное отображение не сохраняется как карта.
5. Не объявляй поддержанными custom CRS, body ellipsoid или time-dependent data до проверки прототипом; до решения обозначь риски и оставь формат/инструмент на оценке.
6. Для климатической классификации используй Köppen–Geiger. Если тело не земное, сначала зафиксируй доступные входы и пределы адаптации; не назначай категории по догадке.
7. Укажи root проекта, доступ/retention для исходников и производных данных; не импортируй/публикуй закрытые данные без разрешения.

**Готово, когда:** цель, body/system ID, набор слоёв, vector deliverable, требования viewer, CRS/data provenance и доступ известны либо явно помечены как открытые блокеры.
