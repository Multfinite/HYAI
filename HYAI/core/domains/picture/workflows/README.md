# Процессы домена `picture`

Во всех процессах ниже **`<picture_root>`** — корень данных из `root_paths` манифеста активного домена `picture` (в самом HYAI — `HYAI/core/domains/picture/pictures`; во внешнем проекте с подмодулем HYAI — собственный путь проекта вне подмодуля, `PIC-POL-06`).

| Процесс | Когда выбирать | Результат |
| --- | --- | --- |
| [`instant.md`](instant.md) | Цельная сцена или объект, создаваемые за один проход на попытку | Проверенный базовый кадр `base-final` в `<picture_root>/stages/` + финальный ассет после `style-filter` в `<picture_root>/assets/` |
| [`pipeline.md`](pipeline.md) | Сложная многосубъектная или высокоточная сцена с поэтапной сборкой | Набор принятых промежуточных звеньев `S1..S7` в `<picture_root>/stages/` + финальный ассет `S8` после `style-filter` |
| [`series.md`](series.md) | Линейка связанных кадров, раскадровка, набор состояний одного персонажа/мира | Утверждённый эталон `series-anchor` + консистентная серия кадров с единым финальным стилем |
| [`style-filter.md`](style-filter.md) | Заключительный проход наложения стиля на готовое проверенное изображение (`PIC-POL-05`) | Стилизованный финальный ассет при полной сохранности проверенной формы, анатомии и текста |

Каркас общих стадий и ворот — ядерный ([`../../../kernel/workflows/README.md`](../../../kernel/workflows/README.md)). В любом процессе домена фильтр стиля накладывается **строго в самом конце**, когда конечное базовое изображение готово (`PIC-POL-05`).
