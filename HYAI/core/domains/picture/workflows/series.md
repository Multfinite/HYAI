# `picture/series`

Рабочий процесс для связанных наборов изображений (раскадровок, иллюстративных циклов, карточек линейки объектов, сцен с сквозными героями), обеспечивающий выполнение правила `Consistency` (`PIC-QA-04`) и отложенной единой стилизации (`PIC-POL-05`).

## Стадии процесса

Во всех шагах `<picture_root>` — корень данных из `root_paths` манифеста активного домена `picture` (вне подмодуля HYAI для внешних проектов — `PIC-POL-06`).

1. **Ворота безопасности серии (`G0-SAF`, `PIC-SAF-01..05`).** Убедиться, что пользователь явно задал `NSFW`, `Copyright`, `Person`, `Violence` для всей серии (а при различиях между кадрами — для каждого отличающегося кадра). Без всех четырёх параметров работа не начинается.
2. **Создание эталона серии (`series-anchor`, уровень `visual-canon`).** По шаблону [`../templates/series-anchor.md`](../templates/series-anchor.md) в `<picture_root>/briefs/` фиксируются:
   - неизменяемый текстовый якорь внешности каждого сквозного персонажа и ключевого предмета (черты лица, причёска, пропорции, одежда, цветовые коды `#HEX + словесное имя`);
   - единые для серии `min_resolution`, список `allowed_aspect_ratios` и `iteration_limit`;
   - якоря окружения серии (`PIC-ENV-04`): свет звезды, флора, небо и небесные тела из канона окружения проекта (`env_canon_source`), одни и те же для всех кадров; смена времени суток или погоды между кадрами — решение автора, а не агента;
   - эталонное базовое изображение персонажа/среды (генерируется через промпт, проходит VLM-приёмку и сохраняется в `<picture_root>/stages/<series-slug>/anchor-base`);
   - единая спецификация отложенного фильтра стиля `target-style`, общая для всей серии.
3. **Построение базовых кадров серии (`style: base-neutral`).** Каждый кадр серии `F1..Fn` создаётся в режиме [`instant.md`](instant.md) либо [`pipeline.md`](pipeline.md) (в зависимости от сложности конкретного кадра) с дословным включением инвариантного блока `series-anchor` в секции `subject` и `lighting`.
   - На каждом кадре VLM помимо стандартной проверки артефактов (`PIC-QA-03`) проводит парное сравнение с `anchor-base` (`PIC-QA-04`): черты лица, рост/пропорции, детали костюма и геометрия сквозных предметов не должны дрейфовать.
   - Окружение сверяется с якорями серии (`PIC-ENV-04`, `PIC-QA-06`): одинаковый свет звезды, одна и та же флора и небо, спутники на своих местах; иначе кадр отбраковывается, а не «объясняется» сменой погоды.
   - Отбракованные дубли удаляются сразу; принятые базовые кадры `f01-base-final .. fn-base-final` сохраняются в `<picture_root>/stages/<series-slug>/` (`PIC-POL-04`).
4. **Единый финальный проход фильтра стиля (`PIC-POL-05`).** Когда базовые изображения `base-final` готовы и сверены между собой по содержанию и анатомии, ко всем кадрам серии применяется **один и тот же** процесс [`style-filter.md`](style-filter.md) с идентичными параметрами секции `style` и весов стилизации.
5. **Сводная VLM-приёмка линейки.** Все стилизованные кадры серии осматриваются единым рядом на отсутствие скачков цветовой температуры, контраста, толщины штриха/зерна и узнаваемости персонажей. Принятые файлы и их карточки размещаются в `<picture_root>/assets/<series-slug>/`.
