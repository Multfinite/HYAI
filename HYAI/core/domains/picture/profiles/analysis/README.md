# `picture/analysis`

Машинное описание профиля — [`profile.yaml`](profile.yaml). Общая часть наследуется из [`../../../../shared/profiles/analysis/README.md`](../../../../shared/profiles/analysis/README.md).

**Тема:** безизменный VLM- и нормативный аудит задач домена `picture`: брифов безопасности, промптов «5+3», конвейеров промежуточных звеньев и готовых серий.
**Мыслительный процесс:** перекрёстная сверка брифа, текста промпта и фактического растра по каждому правилу `PIC-*` с точным диагнозом и ценой вариантов исправления.

## Зона

Основная — `HYAI/meta/reports/**` (наследуется из общего профиля `analysis`). Продуктовый каталог `pictures/**` читается только на проверку.

## Что делает

1. Сверяет полноту стартовых ворот безопасности (`NSFW`, `Copyright`, `Person`, `Violence`, наличие `person_disclaimer`) и соблюдение контуров доступа (`PIC-SAF-01..05`).
2. Проверяет промпты на соответствие структуре «5+3», порогу `MinDetail`, динамическому `negative`, моноязычности и весовому синтаксису модели (`PIC-PRM-01..05`).
3. Проводит VLM-ревизию принятых звеньев и финальных ассетов на разрешение, пропорции, артефакты рук/лиц/текста/геометрии, консистентность серии, отсутствие сохранённого брака и применение фильтра стиля строго в конце (`PIC-POL-04..05`, `PIC-QA-01..05`).
4. Оформляет отчёт `analysis` и при пробелах регистрирует вопросы `Q-PIC-*` в `HYAI/meta/questions/picture.md`.

## Чего не делает

- Не редактирует брифы, промпты и изображения и не запускает перегенерацию в рамках режима разбора (`HYAI-INT-09`).
- Не замалчивает визуальные артефакты и нарушения безопасности ради положительного вердикта (`HELPER`).
- Не ставит статус `approved` (`HYAI-PERM-N05`).
