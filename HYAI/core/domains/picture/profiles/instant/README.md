# `picture/instant`

Машинное описание профиля — [`profile.yaml`](profile.yaml).

**Тема:** создание цельного изображения за один проход генерации на попытку со строгим промпт-контролем, циклом VLM-проверки и заключительным фильтром стиля.
**Мыслительный процесс:** от проверенных ворот безопасности к моноязычному базовому промпту «Каркас 5+3» (`style: base-neutral`), через итерационный VLM-отбор без накопления брака — к сохранённому `base-final` и финальному наложению `style-filter`.

## Зона

Основная — `pictures/prompts/**`, `pictures/assets/**`. Вторичная — `pictures/briefs/**` (чтение/запись брифа задачи) и `pictures/stages/**` (сохранение принятого `base-final`).

## Что делает

1. Проверяет явное задание пользователем всех четырёх правил безопасности (`NSFW`, `Copyright`, `Person`, `Violence`); при нехватке любого останавливается и запрашивает их (`PIC-SAF-01`).
2. Составляет моноязычный промпт по структуре «5+3» (`subject`, `environment`, `lighting`, `camera`, `style: base-neutral`), выдерживает `MinDetail`, явные `weights` под модель и динамический `negative` (`PIC-PRM-01..05`).
3. Ведёт цикл «генерация через промпт → проверка `Resolution` / `Aspect Ratio` / VLM-детекция артефактов → правка промпта» вплоть до `Iteration Limit` (`PIC-POL-03`, `PIC-QA-01..05`), немедленно удаляя бинарники отбракованных попыток (`PIC-POL-04`).
4. Сохраняет принятый базовый кадр `base-final` в `pictures/stages/<slug>/` и только после этого применяет финальный фильтр стиля (`PIC-POL-05`), оформляя `asset-card.md`.

## Чего не делает

- Не создаёт изображения в обход промпта и не подставляет правила безопасности по умолчанию за пользователя (`PIC-POL-01`, `PIC-SAF-01`).
- Не накладывает целевой художественный стиль на сырой или непроверенный кадр до приёмки `base-final` (`PIC-POL-05`).
- Не хранит бинарные файлы неудачных промежуточных попыток и не уходит в бесконечный перебор сверх `iteration_limit` (`PIC-POL-04`, `PIC-QA-05`).
- Не пытается продавить через `instant` сверхсложную многосубъектную сцену после исчерпания лимита — предлагает переход в `picture/pipeline`.
- Не ставит статус `approved` самостоятельно (`HYAI-PERM-N05`).
