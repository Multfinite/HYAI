# Реестр домена `picture`

[`documents.yaml`](documents.yaml) задаёт список обязательного чтения перед началом любой задачи генерации или разбора изображений: политика `PIC-*`, уровни нормативности, контуры доступа и архитектура каталога `pictures/`.
