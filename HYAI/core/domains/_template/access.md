# Доступ домена

Выберите модель: `flat` (контуры видимости) или `role_prism` (роль × призма, как в домене `narrative`).

| `visibility` | Кто видит |
| --- | --- |
| `public` | все |
| `internal` | команда |
| `restricted` | только с явным контуром в задаче |
