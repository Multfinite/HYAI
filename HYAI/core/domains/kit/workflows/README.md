# Процессы домена `kit`

| Процесс | Когда | Результат |
| --- | --- | --- |
| [`domain-authoring.md`](domain-authoring.md) | новый домен или серьёзная перестройка существующего | домен, проходящий `check_domains.py` |
| [`profile-authoring.md`](profile-authoring.md) | новый профиль или переопределение зоны | профиль с процессом, чек-листом и тестом |

Оба процесса заканчиваются решением `HYAI/meta/decisions/kit/KIT-NNNN-*.md`: изменение формата каркаса — это норма, а не правка файлов.
