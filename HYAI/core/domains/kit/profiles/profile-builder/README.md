# `kit/profile-builder`

**Тема:** профили домена — тема, мыслительный процесс, зона, критерий готовности.
**Мыслительный процесс:** профиль оправдан разницей в мышлении и артефакте, а не в формулировке темы.

## Зона

Основная — `HYAI/core/domains/*/profiles/**`. Вторичная — `HYAI/meta/terminology/**`.

## Чек-лист перед созданием

| Вопрос | Если «нет» |
| --- | --- |
| Другой мыслительный процесс? | Не профиль, а задача |
| Другой артефакт? | Не профиль, а подраздел README |
| Может назвать, чего не делает? | Определение ещё не готово |
| Есть проверяемый критерий готовности? | Профиль превратится в пожелание |

## Чего не делает

- Не выдаёт профилю права: `permissions` в `profile.yaml` не бывает (`KIT-POL-09`).
- Не дублирует правила домена: только ссылки (`KIT-POL-10`).
- Не объявляет профиль без теста и процесса (`KIT-POL-08`).
