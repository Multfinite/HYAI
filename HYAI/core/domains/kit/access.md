# Доступ в домене `kit`

Домен плоский: ролей и призм нет, потому что правила каркаса не бывают «для избранных» — они либо опубликованы, либо их нет.

| `visibility` | Что входит |
| --- | --- |
| `public` | README каркаса, инструкции по расширению, шаблоны |
| `internal` | Решения `KIT-*`, спецификации формата, внутренние заметки о миграции |
| `restricted` | Обсуждения уязвимостей каркаса и обходов проверок |

Правило: описание того, как обойти проверку, не публикуется. Описание того, как проверка устроена, — публикуется всегда: закрытая проверка не проверяема.
