# `KIT` — правила расширения каркаса

## 1. Границы самого домена

`KIT-POL-01`. `kit` может создавать и изменять другие домены и их профили. `kit` не изменяет `HYAI/core/domains/kit/**` и `HYAI/core/kernel/**`: обе зоны в `permissions.write.require_approval_for`, правка — только владельцем (`HYAI-PERM-N05`, `HYAI-PERM-G05`).
`KIT-POL-02`. Изменения в чужих доменах объявляются в `cross_scope` отчёта (`HYAI-ART-14`) с причиной: «почему это задача каркаса, а не домена».
`KIT-POL-03`. `kit` не ослабляет проверки: только добавляет. Удаление проверки — отдельное решение с одобрением владельца.

## 2. Создание домена

`KIT-POL-04`. Новый домен создаётся из [`../_template/`](../_template/) и обязан иметь: `manifest.yaml`, `README.md`, `policy.md` с собственными ID, `authority.md` + `schema/authority.yaml`, `access.md` + `schema/access.yaml`, ≥1 профиль, ≥1 процесс, ≥1 шаблон, запись в `HYAI/meta/manifest.yaml`.
`KIT-POL-05`. Домен без собственных правил не создаётся: домен — это предметная область со своей нормативной базой, а не папка.
`KIT-POL-06`. Домен не может занять `root_paths` существующего домена. Один каталог продукта — один владелец.
`KIT-POL-07`. Новый домен проходит `check_domains.py` с первого раза, без правок ядра. Если для домена потребовалась правка `HYAI/tools/*.py` — граница проведена неверно, и это дефект каркаса, а не домена.

## 3. Создание профиля

`KIT-POL-08`. Профиль обязан иметь: `profile.yaml`, `README.md`, ≥1 процесс (`workflow`), непустой `checklist`, `definition_of_done` и строку в тесте домена.
`KIT-POL-09`. Профиль описывает **тему, задачу и мыслительный процесс**, а не права (`HYAI-INT-10`). Права у агента общие; профиль заявляет зону ответственности.
`KIT-POL-10`. Профиль не вводит новый префикс правил: он уточняет правила домена ссылками.

## 4. Удаление и переименование

`KIT-POL-11`. Удаление домена требует: переноса отчётов и решений, обновления `path_map`, решения `P-*`. Удаление «в один коммит» запрещено.
`KIT-POL-12`. Переименование домена — новое имя в манифесте плюс миграция ссылок; идентификаторы решений сохраняют префикс либо получают заглушки (`HYAI-DEC-09`).
