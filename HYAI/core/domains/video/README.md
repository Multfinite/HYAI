# Домен `video`

Руководство для ИИ-агента по планированию качественного видео: brief, сцены/shots, визуальная библия, temporal state, continuity handoff, звук, отдельная обработка шва, ручная приёмка и монтаж. Это **не** runtime генератор: домен не подключает модели/API/ComfyUI и не добавляет зависимости. Пользователь выбирает и запускает доступное средство; агент задаёт процесс и проверяет переданные результаты.

## Основные правила

| Требование | Правило | Практический смысл |
| --- | --- | --- |
| Спросить про звук | `VID-POL-02` | Звук предполагается нужным, но пользователь подтверждает `yes/no`; молчание не считается ответом |
| Уточнить continuity handoff | `VID-POL-04` | До prompts спросить, передаётся ли последний кадр/хвост предыдущего сегмента, другой reference или ничего |
| Обработать каждый бесшовный шов | `VID-POL-07` | Для seam строится отдельное окно вокруг границы; его видео/аудио обрабатывается и проверяется отдельно — простая склейка, необработанный overlap или still-reference сами по себе не устраняют шов |
| Явно договориться о хранении | `VID-POL-03` | Сначала действует правило проекта; если его нет — хранение и удаление согласуются для сессии до медиа |
| Keyframes остаются у `picture` | `VID-POL-08` | В video-проекте только ID/URI/hash и роль референса, без бинарной копии |
| Человек принимает этапы | `VID-POL-11` | Автооценка помогает найти проблемы, но не заменяет одобрение пользователя |

## Зона ответственности

`video` владеет временной структурой, shot-планом, continuity-ledger, sound plan, seam windows, журналами сегментов и монтажной/поставочной документацией в `<video_root>` (`HYAI/core/domains/video/videos/`). `picture` владеет изображениями, keyframes и визуальными сериями; video указывает на эти ассеты через стабильный ID/URI и `sha256` (`P-0003`).

## Профили

- `producer` — brief, ограничения, вопросы к пользователю, storyline и shot/timeline plan.
- `continuity-director` — состояния между shots, handoff method и обязательное окно обработки бесшовного шва.
- `sound-designer` — запрос на звук, звуковые слои, тайминг и проверка аудио на границах.
- `editor` — инструкция ручной сборки, журналы сегментов, техническая/перцептивная финальная приёмка.
- `analysis` — аудит существующего видео-пакета без его редактирования.
