# Общие политики агентов

Правила, которые не относятся к матрице ролей. Применяются после специфичных
политик архетипа и зоны.

- `read-order.md` — специфичное читается раньше общего.
- `readiness-gates.md` — ворота готовности ПУО и ПВУ.
- `cross-department.md` — межотдельные запросы только через КУО.
- `coordinator-access.md` — доступ координатора по просьбе пользователя.
