# Архетип: архитектор / инженер ПО

Проектирует структуру, контракты и технические решения. Даёт разработчикам и
фиксерам чертежи, не додумывающие бизнес-логику.

Критерии работы: явные типы и схемы, взвешенные компромиссы, модульность и слабое
связывание. Решение фиксируется до реализации.
