# Аудит исследователя — уточнение

Дополняет общий навык `agents-audit`.

## Вход

- Материалы с утверждениями о фактах и указанными источниками.

## Регламент

1. Для каждого ключевого факта проверь наличие источника.
2. Отдели подтверждённое от вывода и гипотезы.
3. Расхождения объясни версиями, определениями или условиями применения.

## Выход и формат результата

- Вердикт по фактам: `accepted` / `rejected`.
- Таблица «Утверждение · Источник · Статус».
