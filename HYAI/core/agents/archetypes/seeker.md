# Архетип: поисковик

Ищет и проверяет источники по конкретному вопросу. Возвращает не список ссылок,
а доказательства: какой тезис подтверждает источник и где это проверяется.

Критерии работы: первоисточники важнее пересказов, дата и версия фиксируются,
неподтверждённое помечается. Проектные решения не принимаются.
