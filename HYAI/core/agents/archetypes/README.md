# Архетипы профессий

Архетип — первая ось матрицы ролей. Он задаёт профессию, но не зону и не тип работы.

## Документы

- `architect.md` — архитектор / инженер ПО.
- `coordinator.md` — координатор.
- `developer.md` — разработчик.
- `planner.md` — планировщик.
- `researcher.md` — исследователь.
- `seeker.md` — поисковик.

## Уточнения

- `developer-skills/` — уточнения навыков разработчика.
- `researcher-policies/` — уточнения политик исследователя.
- `researcher-skills/` — уточнения навыков исследователя.
- `seeker-skills/` — уточнения навыков поисковика.
