# `core/agents` — матрица агентов

Источник правил для ролей, навыков и политик агентов. Файлы в `.claude/` и `.opencode/`
являются сгенерированными проекциями; правки вносятся сюда.

## Состав

- `RELATIONS.md` — граф взаимодействий в mermaid, обязателен к прочтению каждым агентом.
- `roles.yaml` — матрица: архетип профессии × зона ответственности × тип работы.
  Пересечение даёт конкретную роль; тип работы может переключаться в процессе.
- `archetypes/<archetype>.md` — информация об архетипе.
- `archetypes/<archetype>-skills/<work>/SKILL.md` — уточнение навыка для архетипа.
- `archetypes/<archetype>-policies/*.md` — уточнение или переопределение политик архетипа.
- `domains/high-head.md`, `head.md`, `executor.md` — поведение на каждом уровне.
- `domains/<domain or zone>-policies/*.md` — уточнение политик домена/зоны.
- `skills/<work>/SKILL.md` — архетипонезависимые навыки: `synthesis`, `analysis`,
  `fix`, `audit` и иные.
- `policies/*.md` — правила, которые не относятся к матрице ролей.

## Порядок чтения

Агент сначала читает специфичные политики и навыки (архетипа, затем зоны/домена),
и только потом общие. Конфликтующие конкретные правила переопределяют общие.

## Навык

Каждый `SKILL.md` специфицирует: что требуется на входе, регламент и алгоритм работы,
что должно быть на выходе и формат результата.

## Генерация

```bash
python3 HYAI/tools/build_agents.py --check   # проверка дрейфа (по умолчанию)
python3 HYAI/tools/build_agents.py --write   # записать проекции
```

Проекции в `.claude/agents`, `.opencode/agents`, `.claude/skills`, `.opencode/skills`
содержат полный текст источников и ссылку на источник: оболочка агента не обязана
разрешать относительные ссылки во время работы. Имена сгенерированных файлов начинаются с
`hyai-` (навыки — `hyai-agent-`); авторские файлы генератор не трогает.

## Файлы и каталоги

- `AGENTS.md` — точка входа для агентов, обязательное чтение.
- `CLAUDE.md` — ссылка на `AGENTS.md`.
- `RELATIONS.md` — граф связей, обязательное чтение.
- `roles.yaml` — матрица ролей.
- `archetypes/` — архетипы профессий и их уточнения.
- `domains/` — поведение по зонам и уточнения доменов.
- `policies/` — правила вне матрицы ролей.
- `skills/` — архетипонезависимые навыки.
