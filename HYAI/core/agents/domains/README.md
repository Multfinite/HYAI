# Поведение по зонам

Зона — вторая ось матрицы ролей. Она задаёт, как агент себя ведёт, кого спрашивает
и где проходят границы его полномочий.

- `high-head.md` — верхний уровень.
- `head.md` — отдел, включая подотдел.
- `executor.md` — сам (рядовой).

## Уточнения

- `head-policies/` — уточнения политик уровня отдела.
