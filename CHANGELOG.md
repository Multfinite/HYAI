## 1.0.0 — 2026-10-22

Первый релиз. Репозиторий самодостаточен: правила, данные и проверки согласованы между собой, история проектирования в него не входит — принятые нормы записаны как нормы.

### Работа с пользователем

[`HYAI/core/kernel/policies/interaction.md`](HYAI/core/kernel/policies/interaction.md) — `HYAI-INT-01..27`:

| Блок | Что задаёт |
| --- | --- |
| Старт сессии | домен и профиль до первой правки, объявление выбора одной строкой |
| Язык и тон | русский, канонические термины, пути без перевода, `HELPER`, маркеры `[Г]`/`[?]` |
| Когда спрашивать | норма `invariant`/`contract`, ворота `PERM-G*`, двойное прочтение, необратимость, конфликт источников |
| Когда не спрашивать | ответ есть в репозитории, правка обратимая, вопрос про вкус, пользователь уже ответил |
| Формат вопроса | 2–4 варианта с ценой, рекомендация, умолчание, свободный ответ |
| Формат ответа | Итог · Изменения · Проверки · Дальше; для разбора — Варианты |
| SPA | автономный HTML в `interaction.spa_dir`, без CDN, `localStorage`, выгрузка конфигурации |
| Ошибки | что не получилось, что пробовали, что нужно от пользователя; без «частичного успеха» |
| Передача смены | отчёт как единственный след: сделано, проверено, не сделано, следующий шаг |

### Идентификаторы правил

| Что | Где |
| --- | --- |
| Схема: `<OWNER>-<CLASS>-<NN>`, владельцы, классы, запрет переиспользования номера | `HYAI/core/kernel/spec/rule-ids.md` |
| Реестр: действующие владельцы и классы, файлы-источники, область ссылок, исключения, `retired` | `HYAI/meta/schema/rule-ids.yaml` |
| Проверка: формат (включая двухчастный класс `PERM-N`), владелец, класс, дубли, висячие ссылки, номера из `retired` | `HYAI/tools/check_rules.py` |

Правила выпуска 1.0.0 писались без класса и без префикса владельца (`PERM-G02`, `INT-21`, `NR-01`). Все они переименованы: `PERM-G02` → `HYAI-PERM-G02`, `INT-21` → `HYAI-INT-21`, `NR-01` → `NR-POL-01`. По старому ID нельзя было понять, чьё это правило, а после правок номера начали означать другое. Все номера исправлены: `PERM-*` → `HYAI-PERM-*`, `INT/ART/DEC/PROV-*` → `HYAI-*`, правила доменов — `<OWNER>-POL-NN`. Карта «старый → новый» — в `retired` реестра: 74 записи, номер не переиспользуется.

Отдельно исправлен дефект самого движка: `check_rules.py` разбирал ID шаблоном, который не понимал двухчастный класс, — 45 правил `HYAI-PERM-N/G/A/P/E/V` не попадали в учёт, а ссылки на них не проверялись. После исправления под проверкой 242 правила и 167 ссылок вместо 197 и 139.

### Каркас не содержит содержания проекта

`HYAI-ART-23`: в ядре, доменах и шаблонах — формы, правила и проверки; имена, топонимы, экономика и сюжеты конкретного мира живут в продуктовых каталогах. Из выпуска убраны все следы проекта, из которого каркас вырос: упоминания рабочего названия системы, вымышленные имена в тестовых фикстурах, служебный домен компетенции конкретного мира. Каталог компетенции остался как пример формы, пустой список служебных доменов — рабочий.

Внедрение в проект — отдельная явная команда адаптации: каркас не знает, куда его поставили.

### Ограничения релиза

- Продуктовые каталоги (`src/`, `tests/`, `docs/`, `specs/`, `diagrams/`, `world/`, `chapters/`, `drafts/`) пусты: это скелет, а не пример проекта.
- `HYAI/meta/project.md` описывает сам каркас; при установке в проект значения заменяются.
- Основа для выгрузок (`build_export.py`, `resolve_access.py`) подготовлена для домена `narrative`; для других доменов контуры объявляются в их `schema/access.yaml`.
