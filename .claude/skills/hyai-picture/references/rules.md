| `PIC-POL-16` | Хранение: один действующий комплект, промежуточное удаляется. |
| `PIC-POL-17` | Контекст между чатами: рабочий журнал не заменяет решение домена. |

| `PIC-POL-24` | Ослабление уже наложенной тени не подменяется перекраской. |

| `PIC-SAF-04` | Person — запрет фотореалистичных реальных людей без disclaimer. |

| `PIC-PRM-04` | Language — единый язык промпта под модель. |
| `PIC-PRM-05` | Weight — корректный и явный синтаксис весов. |
| `PIC-PRM-06` | WorldEnv — окружение кадра по канону мира. |
| `PIC-WF-01` | Разделение рабочих процессов instant и pipeline. |
